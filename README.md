# QR Code Generator

A simple and customizable QR Code Generator built with React, TypeScript, Tailwind CSS, and Vite.

## Features

- Generate QR codes from text or URLs
- Real-time QR code preview
- Customize QR code color
- Customize background color
- Choose QR code size
- Download QR code as PNG
- Reset settings
- Responsive design

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- QRCode.js
